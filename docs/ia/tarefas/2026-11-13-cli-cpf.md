# CLI do módulo cpf (validar, gerar, formatar)

## Pedido original
Crie uma ferramenta de linha de comando para o módulo cpf, com três comandos:
validar (recebe um CPF e diz se é válido), gerar (gera N CPFs fictícios) e
formatar (coloca a pontuação). Inclua testes e documente o uso no README.

## Interpretação e plano (nível 2, planejador)
- `python -m cpf {validar,formatar,gerar}` com argparse (stdlib). Biblioteca nova `formatar_cpf` (cpf/formatador.py).
- Contrato: saída 0 = sucesso/válido, 1 = negativo (inválido / formato inválido), 2 = uso incorreto. `validar` e `formatar` aceitam argumento, `-` ou stdin; `validar` não ecoa o CPF; mensagens de erro nunca incluem a entrada (LGPD). `gerar`: N de 0 a 1.000.000, sempre únicos, `-f`, `--semente`. `formatar` só confere o formato, não os DVs.
- T1 formatador + testes; T2 CLI + testes; T3 README (raiz) + link em docs/humano. Executor: líder (tarefa pequena e acoplada, sem Codex).
