# Documentação para agentes

Conhecimento do projeto em formato curto e estruturado, para leitura e busca por IA.
Busca: `python "$HOME/.software-house/ferramentas/buscar.py" "<termos>"`

- `tarefas/`: registro de cada demanda quando o projeto não usa issues do GitHub.
- `retrospectivas/`: uma por tarefa concluída (skill `retrospectiva`).
- `propostas-obsidian/`: notas que valem para todos os projetos, aguardando aprovação do Bruno.
- Propostas atuais: delegação ao Codex (2026-11-12) e CLI com dado pessoal/argparse (2026-11-13).
- Demais arquivos: um assunto por arquivo (decisão, lição, solução), com título e data.

Mantido principalmente pelo agente `curador-de-conhecimento`.
